# 3.1.2. Линейная и множественная линейная регрессия

Домашняя работа выполнена на данных проекта предиктивного обслуживания промышленного оборудования.

## Задача

Построить модель линейной регрессии для прогнозирования средней мощности оборудования за час — `power_avg_1h`.

## Выполненные этапы

- выбрана вещественная целевая переменная;
- исследованы взаимосвязи между целевой переменной и признаками;
- построены точечные диаграммы;
- выполнено хронологическое разделение на обучающую и тестовую выборки;
- обучены четыре спецификации линейной регрессии;
- рассчитаны метрики MAE, MSE, RMSE, MAPE и R²;
- выбрана и интерпретирована лучшая модель;
- проведён анализ остатков.

## Результат

Лучшей стала множественная линейная регрессия, учитывающая числовые признаки и тип оборудования.

Метрики на тестовой выборке:

- R² — 0,9944;
- MAE — 0,0723 кВт;
- RMSE — 0,0967 кВт;
- MAPE — 3,60%.

Основным фактором, определяющим среднюю мощность, оказался тип оборудования.
