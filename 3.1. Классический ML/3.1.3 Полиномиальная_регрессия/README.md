# 3.1.3. Полиномиальная регрессия

В работе построены модели для прогнозирования средней мощности промышленного оборудования на основе датасета `manufacturing`.

## Целевая переменная

`power_avg_1h` — средняя мощность оборудования за час, кВт.

## Использованные признаки

- средняя температура;
- количество показаний датчиков;
- количество выходов за допустимые границы;
- возраст оборудования;
- количество предыдущих поломок;
- количество обслуживаний за последние 30 дней;
- тип оборудования.

## Выполненные этапы

- исследованы зависимости между таргетом и признаками;
- построены точечные диаграммы;
- выполнено хронологическое разделение данных;
- созданы полиномиальные признаки степеней 1, 2 и 3;
- выполнено масштабирование признаков;
- обучены модели Ridge и Lasso;
- проверены разные значения коэффициента регуляризации;
- рассчитаны MAE, MSE, RMSE, MAPE и R²;
- проанализированы прогнозы, остатки и коэффициенты моделей.

## Результат

Лучшее качество показала Ridge-регрессия с полиномиальными признаками третьей степени.

Приблизительные метрики на тестовой выборке:

- MAE: 0,068 кВт;
- RMSE: 0,095 кВт;
- MAPE: 3,2%;
- R²: 0,995.

Полиномиальная модель уменьшила RMSE примерно на 2%, а MAE — на 5–6% по сравнению с линейной Ridge-регрессией.

Наиболее важными оказались температура, количество выходов показаний за допустимые границы, количество показаний, их взаимодействия и тип оборудования.
